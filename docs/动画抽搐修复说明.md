# 动画抽搐修复说明

## 问题现象

锁屏、AOD（息屏显示）和解锁之间快速切换时，时钟或封面动画偶发回跳、重复进入或短暂闪动。视频中稳定显示阶段没有发现持续性抖动，问题主要出现在系统状态交接阶段。

## 原因

系统界面的睡眠/唤醒回调来自不同线程，而且到达顺序并不固定：

- 睡眠回调会把切换到 AOD 的任务投递到主线程；
- 唤醒回调可能已经在 Binder 线程发生，但之前排队的睡眠任务仍会继续执行；
- `SCREEN_OFF` 广播也可能晚于唤醒回调到达。

旧逻辑只使用布尔状态判断，无法识别“已经过期的睡眠任务”，因此旧任务可能覆盖新的唤醒姿态，表现为动画抽搐或重复切换。

## 修复内容

1. 新增 `ClockLifecycleGate`，为每次睡眠/唤醒生成递增代次，并把代次与状态绑定。
2. 主线程执行睡眠副作用前校验代次；如果期间已经唤醒，则丢弃过期任务。
3. `SCREEN_OFF` 广播仅在当前代次有效时驱动 AOD，避免延迟广播覆盖新状态。
4. 唤醒 token 在首帧消费，或在解锁路径及时确认，避免生命周期卡在 `WAKING`。
5. 时钟唤醒标记改为带代次的 token，防止旧 token 清除新一轮唤醒。

./gradlew :app:testDebugUnitTest

## 手机安装

连接手机并在设备上允许 USB 调试授权后执行：

```text
adb install -r app/build/outputs/apk/release/app-release.apk
```

安装后可用以下命令确认：

```text
adb shell pm list packages | findstr com.os4.musiccover
```
