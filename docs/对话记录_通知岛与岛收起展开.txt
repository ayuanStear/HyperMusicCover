三、通知岛：展开 / 收起的一连串问题
------------------------------------

9) 列表上滑后下拉直接收起
   用户：通知岛展开时，通知列表上滑以后再往下滑收起，会直接收起，而不是第一条数据出来以后再执行
        收起动作；并且收起时触碰到消息会导致消息没有继续往下执行。
   处理：加入"下拉归属"判定（读通知列表自己的滚动量，判断这一拉是列表的还是通知岛的）。

10) 触碰通知后下拉应继续动画，消息应按倒序收起
    用户：下拉时如果触碰了通知，应该继续执行动画而不是选中那条通知；消息应该下滑到最后一条才开始
          展示收起成胶囊岛的动画；参考上游 zyl6932/HyperMusicCover，减少 bug。
    处理：收起改为按趟次依次进岛（上游 byLead 顺序），补上收起收尾兜底。

11) 收起动画不连贯、收不起来
    用户：动画回收不流畅，视频里最后的情况为什么会出现收不起来；过长通知应"第一下拉展示第一条，
          再下拉才收起成胶囊岛"。
    处理：给收起过程加"过了阈值就直接收"与"半路没人推就收尾"的兜底。

12) 胶囊岛音乐卡片弹入卡顿
    用户：胶囊岛音乐展示为音乐卡片的时候，为什么会弹得卡顿一下然后正常。
    处理：定位到卡片与胶囊形变的所有权/连续性，收紧交接时序。

13) 快速点击时岛往下走
    用户：点击快了，音乐胶囊岛会往下走，修复并提交安装。
    处理：修复快速切换时的落点抖动。

14) 收起时从下方出来
    用户：快速切换岛时，音乐胶囊岛是从下方出来又从下方上去的，应该从上方出来然后回收；
          "通知怎么收起的，胶囊岛就怎么收起"。
    处理：把收起路径改成与通知岛一致的三段式。

15) 音乐卡片从下面出来
    用户：还是不对，音乐卡片大岛从下面出来了，应该是胶囊到慢慢消失、卡片慢慢变大直至到位；
          展开/收起时胶囊岛在原地淡出淡入、卡片在原地放大缩小，两边不互相飞。
    处理：改成就地放大缩小 + 淡出淡入，不再互相飞。

16) 参考上游的弹入弹出
    用户：使用 zyl6932/HyperMusicCover 源码里胶囊岛到音乐卡片切换的弹入弹出效果。
    处理：按上游的形变/落点实现调整。

17) 卡片抬升
    用户：快速点击音乐卡片时还是从下面出来；卡片加一个打开向上过渡放大、收起向下缩小的动画。
          最后一版胶囊岛没收起来；音乐胶囊岛应该向上动画的同时缩小，音乐卡片接着放大并落到指定位置。

18) 快速点击抬高 / 背景歌词卡顿

五、常用命令（备忘）
--------------------

编译（离线，需 JDK 17 + Android SDK platform 37）：
    ./gradlew :app:assembleDebug --offline --console=plain

安装 + 重载模块：
    adb install -r app/build/outputs/apk/debug/app-debug.apk
    adb shell "su -c 'kill -9 $(pidof com.android.systemui)'"

读模块状态（只读探针）：
    adb shell am broadcast -a com.os4.musiccover.PROBE --es op mini
    adb shell am broadcast -a com.os4.musiccover.PROBE --es op rowtree
    adb shell am broadcast -a com.os4.musiccover.PROBE --es op fold

制造测试通知：
    adb shell cmd notification post -t '测试通知 1' mcprobe1 '这是第 1 条测试消息'

模块日志（LSPosed 收集，tag 前缀 [MCProbe]）：
    adb logcat -d | findstr /i "MCProbe"
